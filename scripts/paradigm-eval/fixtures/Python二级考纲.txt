全国计算机等级考试二级 Python 语言程序考试大纲（模拟样例，供测试用）

一、基本要求
1. 掌握 Python 语言的基本语法规则。
2. 掌握基本的程序设计方法，能阅读和分析程序。
3. 掌握 Python 常用标准库与第三方库的初步使用。
4. 能够编写、调试和运行 Python 程序，解决简单的实际问题。

二、考试内容

第 1 章 Python 语言基本语法元素
- 缩进、注释、保留字、标识符命名规则
- 基本数据类型：整数、浮点数、复数、字符串
- 变量赋值与引用语义
- 基本输入输出：input()、print()、格式化输出 format()

第 2 章 基本数据类型与运算
- 数字类型运算符与优先级
- 字符串索引、切片与常用方法（split/join/strip/replace/find）
- 字符串编码概念（UTF-8）
- 类型判断与类型转换 int()/float()/str()/eval()

第 3 章 程序控制结构
- 分支结构：if / elif / else、三元表达式
- 遍历循环 for 与无限循环 while
- break / continue / else 子句
- random 库：randint()、uniform()、choice()

第 4 章 函数和代码复用
- 函数定义与调用、参数传递（默认参数、可变参数 *args/**kwargs）
- 变量作用域：局部变量与全局变量 global
- lambda 匿名函数
- 代码复用与模块化设计、datetime 库基本使用

第 5 章 组合数据类型
- 列表：创建、索引、切片、增删改、推导式
- 元组：创建与不可变性
- 字典：键值对、遍历、get()/items()/keys()/values()
- 集合：去重、交并差运算
- jieba 库分词基本使用

第 6 章 文件和数据格式化
- 文件打开 open() 与关闭、读写模式 r/w/a
- 文件读写方法 read()/readline()/readlines()/write()
- with 上下文管理
- 一二维数据的 CSV 格式读写、json 模块
- wordcloud 库基本使用

第 7 章 Python 计算生态
- 标准库：turtle（绘图）、random、time、PyInstaller（打包）
- 第三方库：pip 安装与管理、numpy 基础
- 常用第三方库的获取与安装途径

三、考试方式与分值
- 考试时长 120 分钟，满分 100 分
- 单项选择题 40 分（含公共基础知识 10 分）
- 操作题 60 分：基本操作题 15 分、简单应用题 25 分、综合应用题 20 分
