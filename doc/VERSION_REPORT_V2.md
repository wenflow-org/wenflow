## 三、改造（本版 → 下一版）

- **split-compare 行对齐虚线**：两栏第 n 行之间画对齐虚线（delta.at 分叉行断开）——外盲评读成「两段独立文字」的病灶，把「同一动作的两种走法」画出来
  - 涉及：frontend/src/components/teaching-figure/render.ts
- **state-strip 时基轨道**：帧框外统一一条横轨 + 每帧一个进度点（起点实心），把「不回头」的推进画出来
  - 涉及：frontend/src/components/teaching-figure/render.ts
- **concept-map 环分支标签锚定弧顶**：长弦的标签原从弦中点径向推出会「飘」离弧线，改锚定到弧顶再外推 12px
  - 涉及：frontend/src/components/teaching-figure/render.ts
- **state-strip 指南收紧为状态快照**：帧内 items 只写「主语+状态」快照，禁动作指令/命令行话术（V1 元认知话术 12% 病灶）
  - 涉及：backend/src/services/ai-teaching/teaching-visual.service.ts
- **留白关补「撤点」句**：图上几何对象本身是答案时（要学生写的顶点/交点/落点）连点都不画——V1 泄题病灶：标「?」却把点钉在 (1,-4)
  - 涉及：prompts/core/teaching-turn.yaml
