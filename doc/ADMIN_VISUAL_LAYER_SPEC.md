# Admin 视觉层设计语言（v2，2026-09-25）

> 配套文档：`doc/ADMIN_PAGE_TEMPLATES.md`（骨架与规则，"不含视觉换皮"——本文补上它留白的那个层）。
> 状态：v2 把 v1 的"数值"升格为"硬规则"——2026-09-25 复审结论：admin 丑的根源不是某个值不对，
> 而是**没有一套被强制的语言**（活代码里圆角 15 档、控件高度 12 档、阴影各写各的、
> token 只在纸面上存在——mk-primitives.css 里 32 处圆角硬编码、radius token 仅 3 处被引用）。
> v2 已把原语层全部改写为引用 token（详见 git aa963345 之后的提交）。

## 0. 一句话语言

**平的仪表台**：中性炭灰的面 + 1px 发丝线；蓝只许出现在"可交互/选中"上；
数字一律等宽；形状只有四档；阴影只有三档；控件只有三档高；文字只有三档大。
任何一页，眯起眼看只剩灰阶和一团蓝——就是对的。

## 0.5 硬规则（v2 起逐条可判，违反即打回）

### 圆角：只有 4 档 + 2 个特例

| 档 | token | 值 | 用在 |
|---|---|---|---|
| 内芯 | `--mk-radius-xs` | 4px | 徽章直角变体、代码块、行内小 tag |
| 控件 | `--mk-radius-sm` | 6px | 一切可点/可输入的东西：按钮、输入、下拉、菜单项、胶囊内芯、警示条 |
| 面板 | `--mk-radius-xl` | 12px | 一切"面"：卡片、状态条、pills 容器、菜单弹层、KPI 瓦片、空态图标底 |
| 弹层 | `--mk-radius-modal` | 16px | 模态、抽屉 |
| 特例 | pill / 50% | 999px / 50% | 真·胶囊徽章、头像 |
| 特例 | 4K tier | ×1.15/×1.4 | 仅 `@media` 档位块内允许出现 14px 这类缩放值 |

禁止 5/7/8/9/10/13/22/26px 等中间档（v1 存量里它们各被用了 12-66 处，已全部归档）。

### 阴影：只有三档，面永远是平的

| 档 | token | 用在 |
|---|---|---|
| 平 | 无 | 卡片、状态条、KPI、表格（1px 发丝线就是全部质感） |
| 悬浮 | `--mk-shadow-sm` | 吸顶表头、粘性工具条 |
| 弹层 | `--mk-shadow-pop` | 菜单、模态、抽屉、toast |

- **禁止彩色光晕**（`0 2px 8px rgba(蓝,…)` 之类）与 hover 抬升（translateY）——
  悬停只允许变背景/边框/文字色。
- 选中/激活描边一律 `inset 0 0 0 1px <色>`（见 `.mk-pill--active`），不再用外圈 ring。

### 焦点环：全站一圈

`--mk-focus-ring`（亮 `rgba(44,99,208,.18)` / 暗 `rgba(91,141,239,.32)`），
输入族 = 蓝边 + ring；按钮族 = 纯 ring（`outline: none`）。禁止自写第二圈。

### 控件高度：28 / 32 / 36

| 档 | 值 | 用在 |
|---|---|---|
| sm | 28 | 表格行内按钮（`.mk-btn--sm`）、行内 ⋯ |
| md | 32 | 工具栏默认按钮（`.mk-btn`）、筛选输入/下拉 |
| lg | 36 | 页头主操作（新页面才允许用，存量暂无） |

（v1 存量 24-48px 共 12 档；原语层已收敛，页面 scoped 内的私有控件随各自批次收敛。）

### 色彩角色

中性炭灰做面；**蓝 = 交互**（链接、选中、主按钮、焦点）；**绿/琥珀/红 = 语义**
（只出现在徽章、状态点、语义文字），禁止当装饰。页面 scoped 的私写色按
`design:check` 棘轮只降不升（存量 784 处，Overview 99 / Shell 90 / SessionCockpit 78 为前三个洼地）。

### 数字

数据数字一律 `font-variant-numeric: tabular-nums`（`.mk-table td/th` 已是默认）；
标识符/耗时/字节数用 `--mk-mono`。图表坐标轴与 series 数值同规则（ECharts 用字面量色不解析
CSS 变量，属于登记过的残留，改图表时顺手带 palette 统一）。

## 0. 定位

骨架规范解决"结构一致"；本文解决"看起来有没有设计语言"——四件事：**层级、节奏、透气、质感**。
全部通过共享层（token + 原语）实现，不逐页改样式；密度 compact 档不受影响。

## 1. 层级（Typography hierarchy）

**2026-09-24 收敛**：文本只有**三个角色**，各角色在各响应式档位的值由 token 覆写；
页面只引用角色，不写半像素值。

| 角色 token | 承担的元素 | 基线（<1440） | 1440 | 1920 / 2000 | 2800 / 3600 |
|---|---|---|---|---|---|
| `--mk-fs-micro` | 表头 / 次级说明 / 徽章 / 小按钮 / 字段标签 | 12 | 12.5 | 13 | 15.5 |
| `--mk-fs-body` | 正文 / 表格 / 卡片标题 / 控件 / 链接 / 输入 | 14 | 14.5 | 15 | 17 |
| `--mk-fs-emphasis` | 页头标题 / 空态主标题 / 覆盖层标题 | 15 | 15.5 | 16 | 19.5 |

规则：

1. **同一视口内 ≤3 个文本档**（就是上面这三个角色）。层级靠字重与颜色，不靠加字号——
   卡片标题与正文同档，用 700 拉开。
2. **档位块只覆写这三个 token**，不逐个选择器写字号（`design:check` 规则 13 硬失败）。
3. **展示型字号不占文本档位**：KPI 数字、实体名（`mk-entity__name`）、大标题等
   `> emphasis × 1.15` 的值仍按各自档位放大，用字面量写没问题（规则 13 按这个阈值放行）。
4. 弱化（`--mk-faint`）与次级说明是**颜色**角色，不再配独立字号——它们落在 micro 档。

> 基线（<1440）仍是三值（12/14/15），但低于 1440 的窗口不在管理端桌面验收范围内
> （`doc/re_test/admin-audit-2026-09-24.md` §六），档位验收以 ≥1440 为准。

## 2. 节奏（Spacing rhythm，v1 已落地）

| 项 | 旧 | 新 | 理由 |
|---|---|---|---|
| `.mk-page` 卡间距 | space-3 (12) | **space-4 (16)** | 卡片之间要有"一口气"，12px 下卡片糊成一片 |
| `.mk-page` 顶部留白 | space-3 | **space-4** | 页头不顶格 |
| `.mk-page` 行高 | 1.6 | **1.65** | 中文长句阅读节奏 |
| `.mk-card__head` 内边距 | 9×14 | **11×16** | 卡头呼吸感 |
| `.mk-status` 内边距 / 最小高 | 7×12 / 46 | **9×14 / 48** | 状态条是每页视觉锚点，值得占的空间 |
| `.mk-status` 圆角 | 10 | **12** | 与卡片（12）同族 |

规则：块间距只用 space-4 / space-5 两档；卡内元素间距用 space-2 / space-3。

## 3. 透气（Density）

- comfortable 档（默认）：单视口**最多一张主卡**；表格行高不低于 40px。
- compact 档：现有规则不变（显式覆盖，互不影响）。
- 新页面禁止把 KPI 指标、筛选、表格塞进同一张卡——指标条要么独立成卡，要么进卡头（`VirtualLearners` / `MemoryReview` 两种已验证形态）。

## 4. 质感（Material）

- 卡片：**0 阴影** + 1px line + radius 12（v2 起；`shadow-sm` 只留给吸顶悬浮条）；**不加**渐变/玻璃/大阴影。
- 暗色：质感靠中性炭灰阶梯 bg(#141415) < 侧栏(#1b1c1f) < surface(#202124) < 表头条带(#282a2e)
  的明度差 + 边框，不靠阴影。**注意条带要比卡片亮**——暗色里更暗就读成"卡片上破了个洞"；
  且同一 ΔL\* 在暗端不如亮端可见，台阶要 ≥6 个 sRGB 级。（v1 本节的 surface(1f2227)/bg(16181d)
  蓝灰括号值与"中性炭灰"自相矛盾，系陈旧草稿值，v2 起作废。）
- 色彩：中性炭灰底，蓝只做强调（交互/选中/链接）；语义色仅 badge/tone。
- 禁止：页面私写色值（design:check 基线守卫）、透明度叠透明度、radius 混用相邻两档。

## 5. 守卫与演进

- `npm run design:check`：硬编码色值基线不回升。
- 视觉层改动只允许发生在 token / 原语层；页面级 scoped style 只允许布局（grid/flex/定位）。
- 数值迭代：改共享层 → 真机对比 → 全站生效；永不逐页追。

## 7. 内容宽度（Content width，2026-09-24 补）

通栏不是默认值，按内容形态分三类：

| 形态 | 宽度 | 实现 |
|---|---|---|
| 表格列表 / 观测台 / 编辑器工作台 | 通栏（数据密度优先） | 不加限宽 |
| 表单 / 设置（含 tab 宿主下的多张设置卡） | 限宽 1200px 居中 | `.mk-card--narrow`（单卡）或 `.mk-narrow`（tab body 等容器） |
| 弹窗 / 抽屉 | 按档位放大（`--mk-modal-w-*` / `--mk-drawer-w-*`） | 原语自带，页面不管 |

实测依据：`.mk-page` 在 1440 下可用宽度 1216px，已低于 1200 限宽——**加限宽对 1440 无影响**，
只在 ≥2560 起收敛（3840 叠加 zoom 1.3 后为 1560px，仍大于 1440 的 1184px，不出现"越大屏越窄"）。
判据来自 `doc/re_test/admin-audit-2026-09-24.md` §2.4。
