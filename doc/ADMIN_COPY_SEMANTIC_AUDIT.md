# 管理台文案语义审查（LLM 通读）

> 2026-10-22 用户走查后确立：关键词门禁抓不到「解释性文案」这一类，需要按语义通读。

## 为什么关键词门禁不够

`frontend/scripts/check-ui-copy.mjs` 的 R1–R6 是**句式/词典**规则：分号拼接、隔空指路、交互说明书、
内部词、emoji、同文件复读。它们能拦住「点击…可…」「右上角」这类可枚举的写法，但拦不住语义层面的
解释性文案。被用户点名的原文是：

```
概念掌握 · 证据 · 图谱 · 教学会话 随此切换，记忆与行为基线不变
```

每个词都合法、没有内部词、没有指路词、也不重复，可它整句只是在解释一个开关的作用。同理还有
title 里的大段机制说明（「本块取自当前路径……当前路径 = 正在进行且最近有更新的一条」）、
空态里的数据来源说明（「发起目标对话后自动呈现」）、卡头的定义句（「档位决定走对话还是推理通道」）。
这类句子只能靠**读懂整句在说什么**来判，词表越加越漏。

## 判定标准

只审用户可见文案：模板文本节点，以及 title / hint / description / empty / sub / note / aria-label /
placeholder。代码注释不算缺陷（注释里写机制是给维护者的）。

**删**

- 解释机制：这个数怎么来的、内部怎么编译、通道怎么走、状态怎么流转。
- 复述规则：把界面上已有控件/标签的含义再讲一遍；「A = B」式定义句。
- 操作说明：点击后会怎样、去哪个页签改、先点哪个再点哪个。
- 隔空指路：见右侧 / 在另一个页面 / 去某页处理。
- 自述装配：本卡由哪几项相加、取了哪几条、并列关系如何。
- 同义复读：相邻两处说同一件事。

**留**

- 状态词、读数、单位、阈值与参考区间（如「参考 4–7」「≥ 25 分钟标长时」）。
- 截断/采样披露（如「近 200 条日志内统计」「只渲染最近 4000 字符」）。
- 真正改变处置判断的限定：两个同名读数不同源、人为终止不计入失败率、删除后数据保留。
- 错误/空态里可执行的下一步（重试、清除筛选）。

title 与正文同一标准：只允许一句会改变读者判断的限定；解释「这个区块怎么取数」的一律删。

## 执行流程

1. 导语料：

   ```bash
   cd frontend
   npm run copy:dump -- --out ../outputs/ui-copy-corpus.jsonl
   ```

   每行 `{file, line, text}`，只含中文行，已跳过注释行与测试目录。

2. 按域分给多个子代理并行通读（每域 6–15 个文件）。给每个代理的指令必须包含上面「判定标准」原文、
   绝对仓库路径、以及「只读不改、输出 JSON findings（file/line/quote/kind/reason/replacement）」。
   2026-10-22 的分组：总览与外壳、用户与学习者、虚拟学习者、Skill、模型与接入、运营与健康、
   教学组、成本与评估。

3. 人工合并去重，逐条判 `delete / shorten / keep`。**不盲从**：子代理会把「人为终止不计入失败率」
   这类真限定也报成解释句，合并时保留。

4. 落地后跑三道门：

   ```bash
   npx vue-tsc --noEmit -p tsconfig.json
   npm run copy:check
   npx vitest run
   ```

   改文案会打断锁旧词的测试：按新契约改断言，并在测试名里写明依据（不要 `--update` 基线糊过去）。

5. 浏览器复核：1600/1280 两档看关键页，确认无溢出、空态不空得莫名其妙、卡头无残留句。

## 术语：一个对象一个词

2026-10-22 用户走查「什么叫会话，什么叫目标对话」后定的词表。判断依据是数据表与业务链，不是语感：

| 业务对象 | 数据表 | 界面用词 | 不用 |
| --- | --- | --- | --- |
| 目标澄清那段对话 | `goal_conversations` | 目标对话（阶段叫目标澄清） | 会话、目标会话 |
| 教学会话的集合 / 页面 | `teaching_sessions` | 教学会话 | 会话、学习会话 |
| 单条教学记录（路径里的一节课） | `teaching_sessions` 行 | 课堂（计数用「节」） | 会话、课程会话 |
| 生成出的学习计划 | `learning_paths` | 学习路径 | 课程、计划 |
| 虚拟学习者的仿真运行 | `virtual_sessions` | 运行（如「在跑运行」「无响应运行」「运行记录」） | 会话 |
| 管理员 / 用户登录态 | `admin_sessions` / `user_sessions` | 登录会话（只在该页用） | 会话 |

业务链：**目标对话 → 学习路径 → 教学会话（逐课课堂）→ 学习证据与记忆**。
因此学习者详情概览的两张卡分工是「最近课堂」（逐节课）与「最近目标对话」（逐个学习目标），
不再用两个都叫「会话」的标题并排。

### 保留（有意不删，避免审核者二次踩坑）

- **KPI 副行**：`LearnerCenter` / `TokenCost` / `Users` 等的 hint 是分母、窗口、口径或三态
  （加载失败 / 统计中），不是解释句；`ADMIN_VISUAL_LAYER_SPEC` 的「KPI 只留 label + 数值」
  约束的是「说明性脚注」，两者不冲突。
- **`Addons` 开关的「启用 / 停用」状态词**：`MkSwitch` 的设计契约就是「一个控件 + 一个当前状态词」，
  去掉会让开关失去可见名称；状态词本身是状态，不是描述。
- **`VirtualLabLoadSettings`「实际调用仍占用全站共享额度」**：跨设置生效范围的限定，改变处置判断。
- **`runtime-tab`「覆盖已关闭：模型与超时按平台默认，生成参数仍按 Prompt 文件声明取值。」**：
  解释的是混合状态（一半继承、一半仍读文件），删掉会让上方摘要行读错。
- **`trial-tab`「正式内容以源文件为准…」**：告诉运营这里改不了、去哪改，属可执行的下一步。
- **空态/错误态的下一步**：「重试」「清除筛选」「先生成路径」等保留。
- **登录页右栏（管理控制台 + 四个域）**：产品定位展示，不是字段/状态副标。

### 门禁

`check-ui-copy.mjs` 新增 **R7 冗余副标**：管理端文案命中「（可选）」或「选填」即失败

存量已清零，此后新增会被 CI 拦住。判定口径与本节同步，避免门禁与文档两套标准。
