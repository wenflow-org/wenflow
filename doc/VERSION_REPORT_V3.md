**读法**：
- 几何分三连涨（1.54→1.61→1.64）、删掉张数回到 3（V2 的 7 张 drop 里 split-compare 三张「分叉线指到空处」被空槽对齐修掉）、keep 三连涨——两轮改造的方向被外部盲评确认有效。
- **伪视觉（装框文字）仍是头号病灶（58→54→50%）**：新图型（split-compare/state-strip）占了大头。结构类图型的「降维增益」上限在模型给的 spec——帧内要点/两栏文字本身还是句子，渲染器只能画结构画不出语义密度。下一步方向：Diffusion 混合管线（无字底图+SVG 标注）与结构 spec 的「实体密度」归一化判据。
- V3 元话 21% 回弹与可读 2.43 回落需在下一轮盯：新图型张数从 8 涨到 11，疑似新图型 spec 里的流程话术被连坐判 meta——按图型拆口径再评，避免「新图型被误杀」。
