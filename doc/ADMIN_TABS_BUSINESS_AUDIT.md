## 2. 逐页业务逻辑梳理

每页一段:**业务问题 → 数据 → 支撑操作 → 上下游**。

1. **平台总览**——"现在有没有事、去哪处理"。数据:live boot 11 域(调用/技能/用户/虚拟学习者/拓扑/公告…)。
   操作:6 个跳转卡 + 排查动线(intent URL)+ 测试筛选。下游:全部模块。
2. **用户与学习者**——真实用户管理与学习画像覆盖。数据:users(口径:不含测试/虚拟,有标注)。
   操作:新建/编辑/删除(软删可恢复)/角色切换/筛选/排序/列设置。下游:学习者详情、审计日志。
3. **学习会话**——教学会话生命周期观测(Goal→Path→Learn→总结),目标对话列表,学习路径。
   操作:删除会话(确认框)、分页、筛选、口径切换。下游:会话座舱;失败路径→运营中心待办。
4. **记忆与复习**——记忆痕迹健康(到期积压/归并建议)观测 + 归并审计(观察模式→执行→按次回滚)。
   数据:memory_traces + 审计留档。下游:虚拟学习者画像;PromptEval(模拟输入)。
5. **虚拟学习者**——仿真受众管理(89 个):画像(故事池/运行/日程/记忆池/画像 5 tab)+ 会话座舱 +
   运行/单步测试/删除 + 日期模拟 + autopilot。守卫:无故事不能运行(toast 拦截)。
   下游:会话座舱、批量实验、PromptEval 的 simulated 评估输入。
6. **批量实验**——一次创建多虚拟学习者跑系统级队列实验(目标→路径→学习→跨日衰减)。
   创建人秒回,后台队列推进;失败重试续传;卡死回收在虚拟学习者页联动。
7. **编排结构**——五阶段编排拓扑观测 + 字段血缘(命中率/死字段)+ 漂移对账 + 治理折叠区。
   协议文件为真源,页面只读观测 + 字段路由编辑。下游:Skill 设计页(字段路由闭环)。
8. **Skill 运行**——29 个 Skill 的健康观测(成功率/完成度五档/失败节点)+ 健康检查/漂移/对账。
   下游:执行日志、Skill 设计页。
9. **Prompt 评估**——评估用例库(含 simulated 模式:人设+故事+多轮对话+摩擦预算)+ 批量评估 +
   评估历史。上下游:虚拟学习者(persona 输入)、Skill 设计页(版本验证)。
10. **执行日志**——agent_call_logs 全量观测兜底页:日志/Trace 瀑布/成本分析;错误码人话化;
    失败归因分类;测试筛选;导出。上游:所有模块。
11. **审计日志**——操作/登录双审计(合规视角),列宽窄屏弹性。
12. **模型与接入**——网关连接与模型清单拉取/路由默认/外挂能力;调用与健康视图。
13. **系统工具**——时间推进模拟(只读预览)、Outbox 死信重放(确认+影响面文案)、数据导出、会话安全。
14. **运营中心**——待办四态(反馈/失败路径/死信/草稿公告)结论先行 + 公告/通知/成就/反馈管理;
    待办跳转已联动(失败路径→学习会话,死信→系统工具)。

## 4. 易用性 / 直观性评估

**强项(实测确认)**
- 切换器带计数(如"失败 898"),所见即筛选;
- 切换零等待(pills 即点即切)、危险操作全确认、Esc/遮罩全支持;
- 跳转卡信息先行("失败 367 次"而非"查看日志"),动线带上下文(intent URL)。

**弱项(按影响排序)**
1. 命名双关三处(新手混淆源):「学习会话」页内含「教学会话」tab;ops-center/ops-hub 与
   中文名(系统工具/运营中心)语义错位;「模型与接入」页含「接入与模型」tab。——改名成本低
   但涉及肌肉记忆,建议择机一次性处理。
2. 折叠侧栏单字图标语义弱(览/人/会/忆/拟/批/流…)——折叠态加 tooltip 已有,可考虑折叠时
   保留组标题首字+计数的组合。
3. 编排阶段 tabs 无键盘 role=tab 语义(pills 有 role=tab 的页面已达标)——小项。
