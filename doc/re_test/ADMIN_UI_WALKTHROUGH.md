## 2. 发现的功能故障(1 项；2026-09-22 已修，见 ADMIN_MODULE_BENCHMARK §9)

**Prompt 评估 · 批量跑评估必失败**
- 复现:Prompt 评估 → 批量跑评估 → toast「批量评估失败:模拟学习者 d1628669-33bf-4169-90a3-6cbb74ec3a93 不存在」
- 根因:评估用例「英语」(case-mtofxuqj)引用的模拟学习者已被删除,悬空引用导致每次批量评估失败。
- UI 层表现合格:错误被诚实 toast 呈现(不静默);但功能不可用。
- 建议:用例编辑器对不存在的学习者引用给出标记;或批量评估自动跳过不存在的学习者并在结果中报告(而非整批失败)。
- **【09-22 补注】已修**：批量评估自动跳过悬空用例并在结果里报告理由（PromptEval.vue），本节复现步骤已失效。
