**八版读法**：
- **可读性 2.43→2.73（八版最高）**：token 折行、动态让位、英文长句折行是三连修复的累积。
- **伪视觉 58%→7~10% 稳定**：V5 之后没再反弹；V6/V7/V8 的 fix 已基本不涉及「装框文字」。
- **保留数 V4 达峰（15）后回落到 9~12**：V5 起评审口径按轮意图收紧（纠错轮要求留白、示范轮要求对照完整），V4 的高分部分来自「所有对照都写全」被宽松判读；V6–V8 的 fix 全部是内容层细节（两栏是否同一起点、机制是否展开、数值是否自洽），这正是「管线层已清完、剩下是内容层」的证据。
- **泄题在 7%~17% 区间摆动**：纠错轮（check/co-create）的留白粒度依赖模型对 intents 的判断，V8 的算式/结构核验无法覆盖「留白行选择」这类语义决策——这是下一阶段的真实上限。
- **内容层核验（V8）拦下 1 张算式可疑图、合并 3 组并列边**：确定性核验能兜住「可计算/可结构判断」的错误，兜不住「因果方向写反」这类语义错误（V4 季风、V6 工业革命病灶）——需要知识校验层（独立 KC 图对照）而不是渲染侧。

**结论**：八版下来，管线侧（路由/归一化/渲染/脱敏/内容核验）的系统性问题已经清完；剩余 fix 集中在模型 spec 的语义质量（因果方向、留白择行、机制展开深度），改造成本已从「代码」转向「提示词与知识校验」。下一阶段的杠杆按优先级：① 知识校验层（用上游 kcGraph/anticipatedMisconceptions 交叉核验因果方向）；② critique 路线的 Diffusion 混合管线（无字底图 + SVG 标注，解决「空间场景类图只能画成框」的图型能力上限）。
