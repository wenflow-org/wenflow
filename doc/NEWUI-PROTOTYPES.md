## 2. 原型值残留规则（复刻前必读）

**两个原型文件都是 2026-10-02 归一批之前的产物，其 CSS 值是上一代残留；仓库现在领先于原型。** 复刻时只照抄结构与节奏，**取值一律回 tokens.css**。已知残留（遇到即替换，不要照搬）：

| 残留值 | 管理端原型 | 用户侧原型 | 正确取值 |
|---|---|---|---|
| 旧品牌蓝 | `--brand: #2c63d0` | `--blue: #2c63d0` | `#2f6ae0`（暗色 `#5b8def`，即 `--wf-color-primary`） |
| 圆角 10px 档 | — | `--radius-lg: 10px` | 已砍：面板 12 / 卡片 16（spec §0.5 六档） |
| 渐变主按钮 | — | `linear-gradient(135deg, 蓝→深蓝)` | 禁（守卫规则 17）：主按钮纯色 |
| 彩色光晕投影 | — | `0 10px 22px color-mix(蓝 30%)` | 禁：阴影只用 spec 三档 |
| 毛玻璃材质 | — | —（管理端 §7 顶栏毛玻璃已在 v4 退役） | 禁（守卫规则 18）：`backdrop-filter` 零容忍 |
| 柱条/登录页装饰渐变 | `barchart .bar` 渐变、`login__aside` radial | 进度条 `90deg` 渐变 | 柱条用语义 token 纯色；进度条 `90deg` 渐变是规则 17 明文豁免项 |

一句话：**原型 HTML 里凡是和 spec v4 / tokens.css 打架的值，都是原型没跟上，不是仓库错了。**
