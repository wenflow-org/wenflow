## 测试流程

### 第一步：注册账户
通过前端页面注册三个测试账户

### 第二步：目标对话
以用户身份进入目标对话页面，通过自然对话表达学习需求

**对话要点（以英语学习者为示例）：**
- 第一轮：模糊表达"I want to improve my English"
- 第二轮：被问及具体问题后，透露"I can read but can't speak"
- 第三轮：说明时间限制"I only have 30 minutes a day"
- 第四轮：表达偏好"I hate memorizing vocabulary"
- 第五轮：确认目标和时间线

### 第三步：路径确认
查看生成的学习路径，确认是否符合需求

### 第四步：开始学习
进入第一个任务，体验学习内容

---

## 预期结果

### 英语口语路径
- 12周计划（3个月）
- 每周2-3个任务
- 重点：口语练习场景、常用表达、对话模拟
- 避免大量单词背诵

### 初中数学路径
- 2周计划
- 每天1小时
- 重点：函数概念可视化、实际问题建模
- 包含练习题和应用场景

### 经济学路径
- 2-3周计划
- 每天20分钟
- 重点：通胀/利率概念、新闻解读
- 结合实际案例
