zhang_san = Student("张三", 20, 95)

**周二：继承**
```
理论（18分钟）：
- 什么是继承？（代码复用）
- 父类 vs 子类
- super()调用父类方法
- 方法重写

真实案例：
```
现实中：
- 人（父类）：吃饭、睡觉、说话
  ├─ 学生（子类）：继承"吃饭、睡觉、说话"，新增"学习"
  └─ 老师（子类）：继承"吃饭、睡觉、说话"，新增"教书"

代码：
class Person:
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(f"{self.name}在吃饭")

class Student(Person):
    def __init__(self, name, student_id):
        super().__init__(name)  # 调用父类初始化

    for word in urgent_words:
        if word in content:
            score += 10

    # 类别权重

    return score

    for task in self.tasks:
