## 2️⃣ 游客模式系统

### 2.1 游客身份管理

**功能描述**:
- 用户首次访问时，系统自动生成一个匿名游客 ID
- 游客 ID 保存在浏览器本地存储中
- 游客 ID 用于关联用户的学习数据

**技术要求**:
- 游客 ID 格式：`guest_` + 随机字符串（例如 `guest_abc123xyz`）
- 存储位置：浏览器 `localStorage`
- 生命周期：用户不清除缓存则永久有效

**生成时机**:
- 首次访问网站首页时生成
- 或首次点击"开始提问"时生成

**边界情况**:

| 情况 | 处理方式 |
|------|---------|
| 清除浏览器缓存 | 游客 ID 丢失 → 数据丢失（预期行为） |
| 更换浏览器 | 游客 ID 不共享 → 数据不互通（预期行为） |
| 更换设备 | 游客 ID 不共享 → 数据不互通（预期行为） |
| 无痕模式 | 关闭标签页后丢失（预期行为） |

---

### 2.2 本地数据存储

**存储内容**:

| 数据类型 | 存储位置 | 说明 |
|---------|---------|------|
| 游客 ID | localStorage | 唯一标识 |
| 对话历史 | localStorage | 与 AI 的对话记录 |
| 学习路径 | localStorage | 生成的学习路径结构 |
| 任务进度 | localStorage | 已完成任务列表 |
| 成就徽章 | localStorage | 已解锁成就 |
| 最后活跃时间 | localStorage | 用于清理过期数据 |

**存储限制**:
- 单个域名 localStorage 限制约 5-10MB
- 只存储必要数据（ID、路径 ID、任务 ID 列表）
- 详细内容（对话内容、路径详情）可存在后端缓存（带 TTL）

**数据读写规则**:

**读取**:
1. 页面加载时检查 `localStorage`
2. 有游客 ID → 加载对应数据
3. 无游客 ID → 生成新的

**写入**:
1. 每次操作后更新 `localStorage`
2. 对话完成 → 保存对话 ID
3. 路径生成 → 保存路径 ID
4. 任务完成 → 更新任务列表

---

### 2.3 API 认证策略

**认证方式**:

| 用户类型 | 认证方式 | Header 示例 |
|---------|---------|------------|
| 游客 | X-Guest-ID | X-Guest-ID: guest_abc123 |
| 正式用户 | Authorization | Authorization: Bearer xxx |
| 未认证 | 无 | 允许访问公开接口 |

**接口权限**:

| 接口类型 | 游客 | 正式用户 | 说明 |
|---------|------|---------|------|
| GET /api/goal-conversation | ✅ | ✅ | 开始对话 |
| POST /api/learning-paths | ✅ | ✅ | 生成路径 |
| GET /api/learning-paths/:id | ✅ | ✅ | 获取路径 |
| POST /api/tasks/:id/complete | ✅ | ✅ | 完成任务 |
| GET /api/dashboard | ✅ | ✅ | 获取概览 |
| POST /api/sync | ❌ | ✅ | 多设备同步（仅正式用户） |
| POST /api/export | ❌ | ✅ | 导出数据（仅正式用户） |

**安全限制**:
- 游客 API 调用频率限制：每分钟 20 次
- 游客数据保留期限：最后活跃后 90 天
- 游客 ID 验证：后端验证 ID 格式 + 存在性
- 数据隔离：游客 A 无法访问游客 B 的数据

## 4️⃣ 邮箱绑定流程

### 4.1 触发条件

**触发时机**（满足任一即触发）:
- ✅ 完成第一个学习任务后
- ✅ 生成学习路径后且活跃超过 5 分钟
- ✅ 用户主动点击"绑定邮箱"按钮
- ❌ 首次打开网站时（不触发，太早）
- ❌ 第一次点击任何按钮时（不触发，太早）

**7 天规则**:
- 用户关闭绑定提示后，7 天内不再自动弹出
- 用户选择"不再提示"后，永久不再自动弹出
- 用户可随时主动点击"💡 游客模式"触发绑定

---

### 4.3 绑定流程

**步骤 1：输入邮箱**
```
┌─────────────────────────────────────────┐
│  绑定邮箱                                │
│                                         │
│  输入邮箱地址，我们将发送魔法链接        │
│  无需密码，点击链接即可完成绑定          │

│                                         │
│  [发送魔法链接]  [取消]                  │
└─────────────────────────────────────────┘
```

**步骤 2：发送魔法链接**

**后端操作**:
1. 验证邮箱格式
2. 生成一次性魔法链接（24 小时有效）
3. 发送邮件（模板见下方）
4. 显示提示"请检查邮箱"

**邮件模板**:
```
主题：🎓 完成绑定，继续你的学习之旅

你好！

点击以下链接完成邮箱绑定：

[完成绑定]

链接有效期 24 小时，使用一次后失效。

如果这不是你操作的，请忽略此邮件。

—— AI 学习平台
```

**步骤 3：用户点击链接**

**后端操作**:
1. 验证魔法链接有效性
2. 检查邮箱是否已注册：
   - 未注册：创建新账号，关联游客数据
   - 已注册：关联到现有账号
3. 将游客数据迁移到正式账号
4. 自动登录
5. 跳转 Dashboard，显示欢迎提示

**步骤 4：绑定完成提示**
```

│                                         │
│  [继续学习]                              │
```

### 4.4 数据迁移

**迁移时机**: 用户完成邮箱绑定后

**迁移内容**:
- 所有对话历史
- 所有学习路径
- 所有任务完成状态
- 所有成就/徽章

**迁移流程**:
1. 后端创建正式账号（邮箱为唯一标识）
2. 将游客数据复制到正式账号下
3. 标记游客 ID 已关联正式账号
4. 前端切换为正式用户状态
5. 提示用户"数据已保存，可在其他设备登录"

**边界情况**:

| 情况 | 处理方式 |
|------|---------|
| 邮箱已注册 | 提示"该邮箱已注册，是否直接登录？" |
| 魔法链接过期 | 提示"链接已过期，请重新发送" |
| 迁移失败 | 保留游客数据，提示"绑定失败，请重试" |

## 6️⃣ 数据清理策略

### 6.1 游客数据清理

**清理条件**（满足任一即清理）:
- 最后活跃时间超过 90 天
- 用户主动清除浏览器缓存
- 用户绑定邮箱后（数据迁移到正式账号）

**清理方式**:

## 7️⃣ 数据追踪（匿名）

### 7.1 追踪事件

| 事件名 | 触发时机 | 用途 |
|-------|---------|------|
| guest_visit | 首次访问 | 统计游客访问量 |
| guest_started_conversation | 开始 AI 对话 | 核心功能启动率 |
| guest_generated_path | 生成学习路径 | 核心功能完成率 |
| guest_completed_task | 完成第一个任务 | 用户参与度 |
| guest_bound_email | 绑定邮箱 | 转化率 |
| guest_returned | 再次访问 | 留存率 |

### 7.2 隐私保护

- 不追踪个人身份信息
- 使用匿名 ID（游客 ID）
- 不提供第三方数据共享
- 用户可请求删除所有追踪数据

## 8️⃣ 边界情况与异常处理

### 8.1 浏览器不支持 localStorage

**检测**: 尝试写入 localStorage 捕获异常  
**处理**: 显示提示"您的浏览器不支持本地存储，建议绑定邮箱保存进度"  
**降级**: 使用 sessionStorage（关闭标签页后丢失）

### 8.2 存储空间不足

**检测**: 写入前检查可用空间  
**处理**: 显示提示"本地存储空间不足，建议绑定邮箱释放空间"  
**降级**: 只存储最关键数据（游客 ID + 当前路径 ID）

### 8.3 网络请求失败

**场景**: 生成学习路径时网络失败  
**处理**: 显示"网络错误，请重试"，保留已输入内容  
**降级**: 支持离线模式（缓存 AI 响应）

### 8.4 绑定邮箱已被注册

**场景**: 用户输入已注册的邮箱  
**处理**: 提示"该邮箱已注册，是否直接登录？"  
**选项**: [直接登录] [更换邮箱]

### 8.5 魔法链接过期

**场景**: 用户 24 小时后点击链接  
**处理**: 提示"链接已过期，请重新发送"  
**选项**: [重新发送] [更换邮箱]

## 📞 常见问题

**Q: 游客数据会丢失吗？**  
A: 会。清除浏览器缓存或更换设备时数据会丢失。绑定邮箱可永久保存。

**Q: 为什么不用传统注册？**  
A: 注册是门槛，用户还没体验价值就被要求承诺。游客模式让用户先体验再决定。

**Q: 游客模式如何防止滥用？**  
A: API 速率限制（每分钟 20 次），游客数据 90 天过期，后端监控异常行为。

**Q: 绑定转化率大概多少？**  
A: 行业参考：完成第一个任务后提示，转化率约 30-50%（取决于产品价值感知）。

**Q: 后续可以加密码登录吗？**  
A: 可以。魔法链接登录后，用户可在设置中追加密码。
