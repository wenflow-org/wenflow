## 0. 摘要

本调研覆盖 `prompts/skill.*.md` 全部 **34 个编译产物**（33 个含 coreHash/coreVersion 锚点，`teaching-board-design` 为旧式 frontmatter），对其中**输入通道字段、输出 fields 表字段、规则内引用字段**逐项提取（底表见 4 份 inventory），聚合成 **13 个字段族**，逐族完成学术文献映射（7 份 lit 报告）。

**总体结论**：这套 prompt 字段体系的学术根基显著高于行业平均水平——绝大多数字段族能落到已验证的学术构念上（BKT/IRT 知识追踪、KST 知识空间、KLI 知识组件、Anderson & Krathwohl 二维分类、CLT、ZPD/脚手架、形成性评价、测试效应/间隔/交错、FSRS、ICAP、Weiner 归因、生成式 agent 记忆架构、LLM-as-judge rubric 化、约束解码/可验证指令），且整套教学架构整体落在 VanLehn（step-based ITS，d≈0.76）与 Ma 等（g≈0.41）确认的效度区间内。少数直接以理论命名的字段（`icapLevel`、`knowledgeType` 四分、`personalityTraits` 向量、FSRS 的 `retrievability`）经逐字核实为忠实引用。

三类需要处置的例外：

1. **一条负面证据字段**：VARK 式学习风格（reading/watching/doing/listening）直接沿用被 Pashler et al. 2008 系统审查否定的「学习风格-教学匹配（meshing）」框架，是全部字段中唯一与权威文献正面冲突的设计；
2. **理论姿势越界**：`sdt_needs` 把 SDT「普遍变量」当个体画像读数、SMART 用作硬校验、MI 按 change talk 频次加权（最新复制显示占比与 sustain talk 更有效）、成长型思维若承载成绩效应承诺——均为「出处确凿但用法超出证据边界」；
3. **项目自造无文献口径**：RPKT、CIDDP 五维、愤悱带 0.6–0.8 端点、`sessionLss/sessionLf`、`predictedTone` 三档、`not_judgeable`、含义冻结/coreHash、元规则不暴露、情绪急救三步、求助 `avoidant` 档、`cognitive_bandwidth`、`fatigueRisk` 等——各自有「最接近的文献概念」可锚定，但均属工程折中或平台自建机制，需在文档中显式声明。

**贯穿性主题**：多处概率/计量字段（`masteryProb`、`retrievability`、`stallRisk`、`ktEstimate θ−d`、`confidenceScores`）由 LLM 口径估计而非算法追踪产生——记号可严格标定到 IRT（θ−d 与 2PL 的 θ−b 同构，0.65/0.4 阈值可标定约为 +0.62/−0.41 logit），但缺乏 IRT 的估计程序与校准曲线，存在**伪精度风险**；文献对策是「降格语义 + 证据门控 + 来源标注」。

### 3.1 学习者模型与行为遥测（lit-01）

- 三层投影（knowledgeMemory/profile/dynamicState）与 ITS「学生模型 vs 学习者模型」分工、SMILI:) 框架相容；「自报完成不作真相、结课权威在教师侧」与 OLM「模型=可错信念」及校准文献（自评普遍高估）双重一致。
- **行动项（负面证据）**：VARK 字段若被下游用于「按风格匹配内容形式」即复现被证伪假设。处置：更名 preference（`practicePreferenceNote` 已是正确先例）、prompt 明文禁止风格→形式匹配推理、禁止从偏好推断能力。
- personalityTraits 六维是「行为风格参数」而非心理测量读数（LLM 自评人格跨查询不稳定）；建议措辞改「会话风格画像」并按设定值锚定。
- interactionProfile 六特征全部落在按键/日志分析检验过的特征族内，「current + 近 6 条 history」的个体内基线设计方向正确；但文献明确**支持「辅助情报」、反对「量测」**：响应时与认知负荷关系非单调、依赖标准化任务条件，生理信号都需要 >90 秒窗口。处置：prompt 内避免把该字段语义写成「认知负荷」，改「交互困难/迟滞信号」；stallRisk 的「概率」若为 LLM 主观给出，降格为风险等级（低/中/高）。

### 3.2 知识状态与记忆复习（lit-02）

- **θ−d 可严格标定**：与 IRT 2PL 中心项 θ−b 同构（a=1 时一致）；masteryProb≥0.65 ⇔ θ−d≥+0.62 logit（保守偏严），≤0.4 ⇔ ≤−0.41。初始带 0.40–0.55 围绕 IRT 中性锚点 0.5 的保守收缩，可解释为对 LLM 口径不确定性的先验收缩。
- KC 定义（可独立习得、可单独评估）即 KLI 口径；knowledgeType 四分与 A&K 2001 知识维度逐项一致；prerequisiteTree/RPKT 与 KST surmise 关系及 ALEKS 缺口诊断同构（**RPKT 是自造术语**，最近文献概念是 KST 前置关系）。
- 记忆族对齐度极高：retrievability/next_review 与 FSRS DSR 模型逐字对应；「不预告对比式回捞」命中 Bjork 合意困难四例原文（spacing/interleaving/contextual variation/retrieval practice）；「完成≠掌握」即新失用理论存储/提取双强度分离；提取四态有 SM-2 0–5 质量分作文献先例。
- **行动项**：① masteryProb/retrievability 若为 LLM 口径估计，字段文档注明数据来源，落实「证据数不足时降权输出」；② 交错效应对材料相似性敏感（词表类为负效应），「对比式回捞」需材料门控；③ 提取四态若不回流 FSRS 复习日志（quality 输入）则只是标签，无法驱动间隔重算；④ 课内即时温故成绩有流畅错觉高估风险，掌握口径建议以隔日回捞为准。

### 3.3 目标理解与路径规划（lit-03）

- 最强锚点：first_deliverable/首胜（Bandura 掌握性经验）、implementation intentions（d=0.65 元分析）、学习证据五态↔ITS 强弱项档案、milestones→验收→迁移↔UbD 逆向设计、变式↔顾泠沅/Marton 双传统。
- **行动项（姿势越界）**：① `sdt_needs` 输出语义限定为「本次对话中观察到的需要受挫线索」——SDT 主张三需要是普遍变量而非个体差异；② SMART 从硬校验降级为启发式提示（Doran 原文即警告不可全量化；Swann 系统综述：对复杂/开放目标可能有害）；③ `mi_frames` 的承诺强度建议改按 change:sustain **比值**建模（最新复制：change talk 频次与结局无显著关联、sustain talk 与更差结局相关），并注明 MI 证据全部来自临床行为改变情境、教育迁移无元分析；④ `cognitive_bandwidth` 标注为隐喻性借用（直接文献支持弱）。
- **数值口径三重标准**（zpdDistance 三档 / 85% 规则 / Cognitive Tutor 95% 门槛 / 0.65-0.4 阈值并存）：需在规则层显式声明各自适用环节（规划定位 vs 训练中校准 vs 结业判定），避免「规划档 moderate 但实测正确率 99%」类冲突。
- loadProfile 的 intrinsic load：CLT 理论内部承认要素交互性不可先验估计（Chen/Paar/Sweller 2023），「概念交互密度」应作**序数启发**并允许被实测正确率覆盖（85% 规则路线）。fatigueRisk 为零命中低证据字段，建议标注并以行为信号作运行时代理。

### 3.4 任务设计评估与动机情感（lit-04）

- subtasks→judgeable→exitCriteria 是完整的建构性一致链条；`icapLevel` 忠实引用 Chi & Wylie（四档逐字一致），但 interactive 档在 1:1 人机场景不可达，**需显式降级规则**防模型虚构同伴互动；`cognitiveLevel` 与 `difficultyBand` 正交使用（认知深度≠经验难度），禁止互相推导。
- `falsifiableClaims`（claim/checkOn/expect）是 Popper 判伪结构（modus tollens）的严格转写；`anchorProbe` 是测试效应的实践化；rubric 三档属 holistic scoring，向文献口径靠拢应携带分项准则。
- 动机簇：过程表扬/yet 框架属「反馈话术级」低剂量应用，正反文献都能接受，但 prompt 不得承诺成绩效应（高质量子集 d̄≈0.02 不显著）；求助三分法中 executive/instrumental 出自 Nelson-Le Gall 1981（双转引源确证），**avoidant 档无原文出处**（更接近 ITS help abuse 描述），应注明为操作性扩展；`wantsWorkedExample`+掌握度门控组合同时满足样例效应、渐退机制与专长反转边界，是文献上最完整的字段设计之一。
- `predictedTone` 三档与 `sessionLss/sessionLf` 为**内部分诊标签/内部指标**，与文献情绪离散模型（Pekrun 四象限、D'Mello 线）粒度语义均不同，不可互相宣称等价；下游规则应按「分诊标签」书写。

### 3.5 教学对话与策略（lit-05）

- 整体架构判断：五层输出（回复/诊断/策略/评价装置/掌握估计）等价于把认知导师运行时架构转写为 LLM 回合制输出协议，落在文献效度最高的 step-based 象限（VanLehn d≈0.76；Ma g≈0.41）。
- Meno 闸有精确的同构证据：禁止无前提纯追问 ≈ unassisted discovery（d=−0.38，文献判负），保留阶梯式提问 ≈ guided discovery（d=0.30，文献判正）。
- 掌握证据口径（行动证明/无提示/答对=无提示）与认知导师「以解题行为更新掌握概率」及 Hattie 反馈四层（自我层最无效）同构。
- **张力点**：愤悱带 0.6–0.8 是类比式工程折中（85% 规则刻画的是训练误差率而非学生可解率；0.8 略低于理论最优 0.84；0.6 端点无直接出处）；8 策略枚举是离散封闭集，丢失文献中「条件化」维度；θ−d 若题目参数未标定只是记号借用（且 d 与文献效应量 d 符号冲突）；POE 的「观察」环节被重定义为系统揭晓；protégé effect 依赖可推理的真实被教者，LLM 对话中对象缺失属类比迁移；「愤悱」（《论语·述而》）的求助动机状态在两个西方构念中均无对应变量，属项目自有补充。

### 3.6 多模态与课堂组织（lit-06）

- 图文互锁 = Mayer 冗余效应的直接工程化；双通道重构（结构→mermaid / 空间→确定性 SVG）可由 Larkin & Simon + Zhang & Norman + DeFT 联合支撑；固定输出模板 = 构图决策「样例化」；mermaid+SVG 与 LLM 图示生成的工程收敛路线一致。
- **术语风险**：「双通道」在文献中指认知加工通道（CTML）或言语/表象双系统（Paivio），项目的「双通道」是输出格式分流规则——同名异义，需防「已实现 CTML 双通道」的过度解读。另：13 类 kind 全部默认「出图」，缺「何时不出图」的负向约束（Larkin & Simon 标题即 "sometimes"）。
- 课堂组织：checkpoint/warmup/wrapup/parkingLot = AfL 证据循环；controls/知识看板 = 编排控制面；开场三模式各有实证锚点（example-first→样例、predict→PF、self-assess→AfL 自评）；replan-attribution「归因指向策略而非能力」逐字落实 Weiner 可控性原则。
- **张力点**：AI 同伴是「示范性同伴」而非互惠互教结构（peer tutoring 元分析效应建立在真人互惠上，不可直接外推）；归因主体错位（Weiner 的归因是学习者主观知觉，系统的 `primaryReasonCode` 若直接呈现给学习者可能变成贴标签）；wait-time 在对话式 AI 中难以兑现（Rowe 的机制是物理静默）；recentEvents 仅 5 条，AfL 强调纵向证据，断线恢复后需重验证。

### 3.7 仿真裁判与元技能（lit-07）

- 仿真：personaSeed story≈预置记忆流、memory-curate≈检索+反思层（Park 2023 逐项映射）；friction 摩擦预算 = error-based training（RCT 证据）+ epistemic control（2026 效度研究核心结论：教育有用性取决于认知控制而非流畅度）的字段化；「私有状态连续性+能力悖论泄露」在文献中有先例（误解状态转移与话语解耦、确定性规则管理）。
- **裁判效度是本域最大风险**：referee 与被评者同为 LLM，「独立旁路」只是 prompt 层隔离，自偏好/位置/冗长偏差仍在（MT-Bench/JudgeLM/FairEval）；固定权重合成需自证不放大分项噪声（analytic 分项更不稳定）；actor-audit 是补救但审计本身需与人评对齐才能闭环——仅约 3% 的模拟学习者研究做事后验证，平台的「无锚自检」风险真实存在。行动项：人工锚点抽样校准、考虑跨模型验收、用复测一致性数据持续验证 referee 温度口径。
- 元技能：generate-then-check 恰好落在 CoVe 注意力隔离与 Huang「内在自修正退化」两条证据线的交点上，「验证器中立」有直接文献先例（CoVe factored 变体）；requiredFieldIds/字段冻结 ≈ IFEval 可验证指令 + 约束解码「结构保证」的应用层等价物；温度分档与两组实证（判决端低温 ICC≈.87、高温一致性下降错误率上升）方向一致。
- **自建机制（无学术对应物，需自证）**：含义冻结/coreHash、元规则不暴露（IPI 文献无定量防护评估；是纵深防御之一而非安全边界）。

## 4. 横向议题

### 4.1 「LLM 口径估计 vs 算法追踪」——最大的贯穿性效度主题

涉及字段：`masteryProb`、`ktEstimate θ−d`、`retrievability`、`stallRisk`（概率语义）、`confidenceScores`、`sessionLss/sessionLf`、`selfAssessmentAccuracy`、referee 分项分。共同结构：**记号与阈值借用计量学传统（IRT/BKT/FSRS/校准研究），但数值由语言模型主观给出，无参数估计、拟合检验与校准曲线**。 θ−d 是正面案例：它可严格标定到 2PL（阈值 +0.62/−0.41），初始带 0.40–0.55 的保守收缩是自觉的效度管理；但它同时是伪精度的范例——IRT 的 θ 与 b 需经题目标定，未标定时只是记号外衣。

统一对策（三步，适用于全部此类字段）：
1. **降格语义**：概率→等级/带；「量测→线索」；「预测→分诊」；
2. **证据门控**：evidenceCount/independentCount 不足时降权输出（底表已有字段，需在规则中固化）；当前提取强度口径与隔日回捞口径分离（防流畅错觉污染掌握口径）；
3. **来源标注与双轨**：字段文档注明数值来源（LLM 口径 vs FSRS/KT 引擎原生输出）；长期方向是接真引擎（FSRS 已在用；KT 侧可从 checkpointVerdict 的判定日志积累作答数据）。

## 5. 研究缺口与 prompt 再开发建议

### P1 学术正确性（改动小、收益直接）

1. VARK 字段更名 + prompt 加「禁止风格→形式匹配、禁止偏好→能力推断」两条负面规则；
2. `icapLevel` 加 interactive 档 1:1 降级规则；
3. `sdt_needs` / SMART / `mi_frames` 按 §3.3、§4.3 降格或改口径；
4. 遥测/基调类字段措辞从「量测/概率」改「线索/等级/分诊」；
5. 动机话术簇（过程表扬/归因/正常化）加「不承诺成绩效应」的输出约束。

### P2 效度闭环

6. masteryProb/retrievability 类字段：来源标注 + 证据门控固化 + 「LLM 口径 vs 引擎原生」双轨声明；
7. 数值口径矩阵（§4.2）在 path/teaching 规则中显式分工；
