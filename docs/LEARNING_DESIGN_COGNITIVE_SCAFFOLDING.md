# 学习设计北极星：从「知识拆解」到「认知脚手架」

- 日期：2026-11-10
- 性质：设计方向纪要 + 已落地规则映射 + 待决清单（讨论源：外评 #6 去理论化、#7 教案步骤当课程目录、店员盘库透镜论、远迁移讨论、说明书 vs 认知脚手架讨论）
- 状态：原则已大部分落地（见 §4）；四个待决项见 §6

## 1. 一句话主张

学习路径的组织单元既不是知识点，也不是操作步骤，而是**认知透镜**：为了解决用户的终极问题，学习者必须跨越的那几个认知盲区。知识不是按章节拆好递过去的，而是在跨越盲区的挑战里按需递到手上的。

## 2. 三层次原则（2026-11-10 外评定型）

1. **不给操作指南**：目标是「解决一次蓝屏」的用户存在的是**信息缺口**，不是认知缺口——直答排障步骤，不建路径。一句话能讲透的诉求（均线判读）同理。
2. **不给知识切片**：「学心理学」不能拆成心理学史/三大流派/神经基础——大纲式拆解抽离真实语境，学习者拿到的是目录不是能力。
3. **提供认知透镜**：路径由有张力的现实挑战构成（「为什么明知熬夜不好却停不下来？」→ 认知失调框架；「广告里的洗脑术怎么识别？」→ 行为主义框架），挑战在前、真名理论按需亮剑、用户自身任务收口。

## 3. 理论与实证依据

- **远迁移罕见**：Sala & Gobet 对国际象棋/音乐/工作记忆训练的系列元分析结论一致——远迁移效应趋零，且「效应量与实验设计质量负相关」。传统教育近迁移易、远迁移难是主流共识（Thorndike 共同要素说 → 远迁移依赖共同认知要素）。
- **锚定式教学（抛锚式，Jasper Woodbury 系列）**：把学习锚定在真实问题宏语境里对抗惰性知识；但 Jasper 是 6-10 个场景的**系列**——单个锚点撑不起远迁移，透镜必须在任务外换场景变式。
- **新手不能纯启发**：Kirschner/Sweller/Clark 2006 与 Hmelo-Silver 2007 的回应指向同一处——全新手没有图式，纯苏格拉底提问只剩瞎猜；问题切入之后必须「亮剑」给出真名与答案框架，提问只是切入不是教学主体。
- **实践含义**：透镜要少而真（按任务自然形状 1~5 个）、每个透镜配任务外变式、误区预判要能落成可判定的检查题。

## 6. 待决清单

- **D1 排障簇并入 answer_only**（方案已给待拍板）：三条件 0/3 ×（理解簇 ∪ 排障求助簇）× 无表现要求 → 直答。「练到能自己修」类表现要求仍留路径；复发性故障（修了又犯）三条件命中 ≥1 自然留路径。落地含 3 条 jest + 蓝屏入 AB 回归集。
- **D2 透镜真名与 SOP 练手场条款**：非学科任务的「理论亮剑」= 该领域成熟实务模型的真名（ABC 分类、先进先出、PDCA、5Why、复式记账…）；SOP 只能作为沙盘练手骨架被引用，每条步骤必须配「什么时候失效、失效时用什么判据」；透镜数量按任务自然形状提取，禁止凑数。
- **D3 透镜变式**：每个透镜必须在任务外至少换一个场景变式练习（单锚出不了远迁移，见 §3）。
- **D4 误区前置问句**：见 §7 提案。
- **D5 外部判官固化**：AB 回归集收录均线/苯乙烯/合同案/英文综述/黄山戒手机/蓝屏；苛刻教研专家人设的判官 prompt 存档，每次动 triage/prompt 后重跑。

## 7. 误区前置问句提案（D4，2026-11-10 新增讨论）

外评提议：生成路径前强制 AI 先回答「学习者在解决这个终极目标时，最容易陷入的认知误区是什么？」

**立场：需要，但以「规划前自答三问」的推理规则落，不新增信封字段。** 死区反思的教训是「模型被逼着每轮填表」制造死板感——这是规划期一次性推理，不是逐轮表单：

1. 一问：用户拿这套能力去做的**真实交付**是什么（已有 first_deliverable，复用）；
2. 二问：为跨过终极目标，学习者**最典型的认知误区/盲区**是什么（新增）；
3. 三问：每个误区用什么**透镜+变式**来破（新增，衔接 D2/D3）。

**防编造判据**（必须写进规则）：每个误区必须能落成「一道多数人会答错的检查题」或「一个会翻车的沙盘动作」——落不出来的误区是装饰，删。教自然拼读说不出「中国学生最容易把 θ 读成 /s/」并给出一道暴露它的题，就是没真找到误区。

**与已有规则的衔接**：stage-designer 的教学五步已有「反例」环节——那是任务级呈现误区；本提案是路径级用误区**选透镜、排阶段**，两层互补不重复。
