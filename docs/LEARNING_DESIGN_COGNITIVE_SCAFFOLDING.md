# 学习设计北极星：从「知识拆解」到「认知脚手架」

- 日期：2026-11-10
- 性质：设计方向纪要 + 已落地规则映射 + 待决清单（讨论源：外评 #6 去理论化、#7 教案步骤当课程目录、店员盘库透镜论、远迁移讨论、说明书 vs 认知脚手架讨论）
- 状态：原则已大部分落地（见 §4）；四个待决项见 §6

## 1. 一句话主张

学习路径的组织单元既不是知识点，也不是操作步骤，而是**认知透镜**：为了解决用户的终极问题，学习者必须跨越的那几个认知盲区。知识不是按章节拆好递过去的，而是在跨越盲区的挑战里按需递到手上的。

## 2. 三层次原则（2026-11-10 外评定型）

1. **不给操作指南**：目标是「解决一次蓝屏」的用户存在的是**信息缺口**，不是认知缺口——直答排障步骤，不建路径。一句话能讲透的诉求（均线判读）同理。
2. **不给知识切片**：「学心理学」不能拆成心理学史/三大流派/神经基础——大纲式拆解抽离真实语境，学习者拿到的是目录不是能力。
3. **提供认知透镜**：路径由有张力的现实挑战构成（「为什么明知熬夜不好却停不下来？」→ 认知失调框架；「广告里的洗脑术怎么识别？」→ 行为主义框架），挑战在前、真名理论按需亮剑、用户自身任务收口。

## 3. 理论与实证依据

- **远迁移罕见**：Sala & Gobet 对国际象棋/音乐/工作记忆训练的系列元分析结论一致——远迁移效应趋零，且「效应量与实验设计质量负相关」。传统教育近迁移易、远迁移难是主流共识（Thorndike 共同要素说 → 远迁移依赖共同认知要素）。
- **锚定式教学（抛锚式，Jasper Woodbury 系列）**：把学习锚定在真实问题宏语境里对抗惰性知识；但 Jasper 是 6-10 个场景的**系列**——单个锚点撑不起远迁移，透镜必须在任务外换场景变式。
- **新手不能纯启发**：Kirschner/Sweller/Clark 2006 与 Hmelo-Silver 2007 的回应指向同一处——全新手没有图式，纯苏格拉底提问只剩瞎猜；问题切入之后必须「亮剑」给出真名与答案框架，提问只是切入不是教学主体。
- **实践含义**：透镜要少而真（按任务自然形状 1~5 个）、每个透镜配任务外变式、误区预判要能落成可判定的检查题。

## 6. 根问题（讨论的收敛：case 只是投影，根问题只有三个）

2026-11-10 讨论 correction：盘库/蓝屏/心理学/词根词缀都是随口举的 case，**设计不能对着 case 建规则**（关键词表、场景白名单都是 case 过拟合——换个措辞就失效，且与 #6 土味病同源：拿词面冒充语义）。case 背后只有三个根问题：

### R1 路由的本质 = 缺口类型判断，不是词面匹配

> 2026-11-10 深夜修订：原议「新增 gapType 字段」作废——understanding 已有 4 套分类字段（intent_type / primary_block_type / skill_nature / platform_judgment），蓝屏与乐器的底座已在其中。落法改为 primary_block_type 提权至第 1 轮判定 + 轻量 `response_mode_hint`（answer_only / answer_then_hook / learning_path / physical_decline），详见评审稿 §9 方案二修订。

用户开口时的目标在三个**根维度**上取值，case 只是它们的投影：

| 根维度 | 取值 | 路由 |
| --- | --- | --- |
| **缺口类型** | 信息缺口（答案已知于世界，取回即可）/ 认知缺口（需要在脑内建构结构）/ 练习缺口（结构已在，差表现自动化） | 信息缺口→直答；认知/练习缺口→路径 |
| **复用广度** | 一次性解决 vs 可迁移能力 | 与三条件测试同源（复现×耦合×代价） |
| **利害结构** | 有无学习者之外的真实验收方 | 已有一句话讲透测试 |

蓝屏=信息缺口×一次性；均线=认知缺口但一句话可讲透=信息缺口；系统学排障=认知缺口×可迁移；刷题秒拆=练习缺口。**判语义交给模型，判结构交给纯函数**（本系统既有架构：模型抽取 recurrence/urgency 同款）——落法：goal 会话 understanding 显式抽取 `gapType`（信息/认知/练习），纯函数裁决 `信息缺口 × 三条件低 → answer_only`；现有理解簇正则降级为测试兜底，不再新增任何关键词表。

### R2 路径的阶段单位 = 认知盲区，不是知识单位也不是动作单位

知识拆解（大纲逻辑）、操作步骤拆解（SOP 逻辑）都不是学习逻辑。原 D2/D3/D4 是同一根规则的三面，合并为一条「**排阶段前自答三问**」（机制详见 §7）：

1. 终极交付是什么（复用 first_deliverable）；
2. 最典型认知误区/盲区是什么（每个误区配一道暴露它的题，配不出就删）；
3. 每个盲区用什么透镜+任务外变式破（透镜按任务自然形状 1~5，禁止凑数；变式见 §3 单锚不出远迁移）。

配套措辞扩展：「理论亮剑真名」原则从「学科术语」扩展为「**学科或实务体系的真名**」（ABC 分类/先进先出/PDCA/5Why 与珀尔因果图/共轭效应同格）；「SOP 只能作为沙盘练手骨架被引用，每条步骤必须配『什么时候失效、失效时用什么判据』，配不出的步骤不出现在课程里」。

### R3 验收必须外置，不内卷

内部自评是自证闭环（自己做的菜自己尝不出咸淡）。原 D5：AB 回归集（均线/苯乙烯/合同案/英文综述/黄山戒手机/蓝屏——case 是回归样本，不是规则素材）+ 苛刻教研专家人设判官 prompt 存档，动 triage/prompt 必重跑。

### R4 提问的合法前提 = 已供给的积木（开放度随积木衰减）

苏格拉底悖论（Meno's Paradox）：什么都不懂的人连「该找什么」都不知道，纯提问对他不是启发是**认知霸凌**——脑子里没有积木，让他怎么搭房子。外评给的回合公式：**具象化场景（给靶子）→ 打破直觉（拆旧房子：点破普通人会怎么做、为什么错）→ 供给积木（大白话亮真名）→ 定向启发（在刚给的结构里做选择/填空）**。

系统现状（teaching-turn.yaml）：回合意图三分已砍「每轮必盘问」、探索预算已封顶「诊断性追问 ≤2 轮，第 3 轮必须给机制」、认知负荷三路由已管连错崩溃（frustrated → 正常化+拆小步）——「错误模式」的大半已被拦住。**缺口是「提问前提审计」**：没有任何规则自查「回答这个问题所需的积木，学习者手上有了吗」。planned 误区的「很多人在这里会先以为…你是怎么想的？」（L118）和易错 vs 正解 split-compare 图（L59）已实现「拆直觉」的 case 版，缺的是把它上升为全回合纪律。

**落法**：teaching-turn.yaml 一条规则——提问前自查积木：没有 → 先给（场景/拆直觉/真名），问题改定向（选择/填空）；有 → 正常问。**外评的「绝不提出开放式问题」是白纸特例，根规则是匹配函数：开放度随积木衰减**——掌握度高位 + bored 的学习者走 challenge 路由（L126），对其要开高阶开放问句制造张力，终身填空是把人当傻子。这正是脚手架衰减（scaffolding fading）的本义。

## 7. 三问机制细节（R2 的核心，2026-11-10 提案）

外评提议：生成路径前强制 AI 先回答「学习者在解决这个终极目标时，最容易陷入的认知误区是什么？」

**立场：需要，但以「规划期自答」推理规则落，不新增逐轮信封字段。** 死区反思的教训是「模型被逼着每轮填表」制造死板感——这是规划期一次性推理，产出直接决定阶段排布（第一阶段的入口挑战=暴露头号误区的那道题），不是新表单。

**防编造判据**（必须写进规则）：每个误区必须能落成「一道多数人会答错的检查题」或「一个会翻车的沙盘动作」——落不出来的误区是装饰，删。教自然拼读说不出「中国学生最容易把 θ 读成 /s/」并给出一道暴露它的题，就是没真找到误区。

**与已有规则的衔接**：stage-designer 的教学五步已有「反例」环节——那是任务级呈现误区；本提案是路径级用误区**选透镜、排阶段**，两层互补不重复。

## 9. 工程决策记录（2026-11-10 晚，语音讨论收敛）

### D-A 教学策略路由：确认「软路由 + 确定性底线」，不建硬分流

- **现状即软路由且已运行多时**：回合意图三分、认知负荷三路由（loadIndex 阈值分档）、情绪路由（frustrated/confused/bored 分诊）、求助分流（helpSeekingType）、challengeLevelCap/paceMode——全部是「模型基于完整上下文自评 → 规则内微调」形态，没有写死的分流树。
- 比外评「纯软路由」多一层：**确定性闸守底线**（STAGE_MINIMUMS、triage mode、坚持两次放行的 nudge-gate）——模型判语义、纯函数守结构，漂移有底。
- 外评「状态机指令：挂起主线→切补充分支→切回」在系统里已有对应机制（confused×2 → 停止追问改完整示范；planned 误区提前铺垫辨析；重排链整体重建），不新增状态机。
- **目标阶段不设硬分流选择题**：那是自动化客服逻辑 + 又一张表（死区教训）。用户分型的职责由 R1 的语义抽取（gapType）承担——同为软路由。

### D-B 画像卡点外部评估：R3（验收外置）在画像上的实例化

规格五条：

1. 样本：虚拟学习者流水线批量产课堂数据（黑盒 runner 已有）；
2. 被评对象：learner-model-agent / teaching-turn 抽取的卡点、迷思、干预点；
3. 判官：独立高阶模型，**必须同时携带课堂上下文与学习者历史上下文**——只看单堂会话，会把「基于历史的合理推断」误判成幻觉（或反之），这正是用户强调「全都带进去」的原因；
4. 产出：1-5 分 + 一句话致命偏差；
5. 门槛：通过率阈值（≥80% 立住；低于则改抽取 prompt 再批跑）。

判官先例已在本仓库（prompt-lab semantic-freeze-judge、prompt-ops simulated-eval-engine、virtual-learner-referee）——工程上是组装批量 eval 脚本，不是新架构。

### D-C 认知负荷精度边界：工程闭环大过科研精度

- 现状即务实形态：loadIndex 是模型粗估 + 阈值三路由，从无科研精度主张。
- 决策：**保留升降，不追测量**——精确负荷测量（眼动/EEG/HRV）是科研院校的题，平台的验收标准只有一条：「连续受挫时，下一课主动降难度给喘口气的任务」这个体验闭环成立。用户在乎的是「AI 居然懂我累了」，不是后台 3.5 还是 3.8。
- 跨课负荷消退由 behavioralProfile 跨会话行为压缩部分承担（frustrationRate / 近期行为基线进下一课的节奏基线），不另建跨课负荷状态机。
- 防自挖坑条款：未来任何人想引入「更科学」的负荷测量，先回到本条重新论证——论证义务在提出者。

### D-E 时间语义三分离（2026-11-10 用户拍板）

「评审建议用 Exit Node 替代时长帽」的张力，按时间来源拆成三层，各管各的：

| 层 | 谁说了算 | 系统落点 |
| --- | --- | --- |
| **内容体量预估**（不可预估时） | **AI 建议**——整体设计是动态调节的 | objectiveScopeHours（「内容需要多少，不是日历能学多少」，禁拿可用容量硬乘）+ 颗粒度档位。时长帽语义从「硬上界/承诺」重述为「**建议锚 + 防跑飞校准器**」——防 2.1h 失控的钳制**保留**（那是实证修过的复发护栏），但措辞上不再是承诺 |
| **用户确定时间**（考试日/起用日） | **按用户走** | deadlineDate / deadlineText 在场时排期、压缩（replan compress / replanRatio）一律以用户 deadline 为准 |
| **执行期收口**（课/阶段何时结束） | **Exit Node 认知闭环判据**（方案一落地） | 不看分钟：入口翻车挑战 → 接住真名透镜 → 独立通过 1 道任务外变式，闭环完成即收口；卡住按探索预算兜底结课 |

依赖关系：Exit Node 需 R2 三问产出的「头号盲区检查题」先行——同一批（方案一）落地；时长帽仅在提示词措辞层重述，钳制代码不动。

| ⑤ UI「可用即完美」是逃避 | **挂账（本轮未答）** | 后台 / dashboard / 看板维持简陋合理；但**聊课堂就是产品本体**——苏格拉底体验活在对话 UI 里，目标会话与第一节课的对话体验不适用「可用就行」，这条长期挂在心上，不因本批判立刻动工 |

## 11. D-D 间隔迁移：FSRS 的 payload 升级（2026-11-10 提案采纳）

外评提案：FSRS 只管「何时触发」，payload 从「复述旧知」换成「新情境微型挑战」。对照仓库现状，**调度半边已经全部建成，不要碰**：

- 已有：FSRS 状态（learner-model-agent / memory-traces）→ 温故计划（review-plan：CLT 负荷预算、85% 检索成功率动态校准、单课 ≤3 硬上限）→ 教学回合开场回捞 → **结构化结果通道 warmupOutcomes**（2026-09-17 起，替代靠提示词依从性当传感器的旧法，旧法丢样 ~50%）→ rating 映射回 FSRS（ReviewCompletedConsumer）。
- **要动的只有 payload 一半**：温故注入从「回捞旧知」升级为「新情境变式挑战」——载荷携带该概念的误区检查题 / 任务外变式。**这正是 R2 三问的检查题与 D3 变式的同源机制：一套机器，课内用来教、到期用来复习。**
- 预算口径（2026-11-10 评审收敛，替代原「1.5-2× 预算乘数」）：迁移挑战的检索努力远高于纯复述，**不乘系数、直接硬上限——单课开场最多 1 道迁移挑战**，其余到期概念顺延下一课或降级为一句话带过，防止温故变成本课新负担。
- 判分：沿用 warmupOutcomes 结构化通道，**不做用户自报（太难/刚好）主通道**（有偏差且丢样）；温故片段抽样进 D-B 判官审计，防同源自评。
- 工程量：prompt 侧为主（teaching-turn 温故规则改写 + session-wrapup 检索种子同步改迁移种子）+ 温故计划条目携带误区字段的少量 service 改动。
