# 联网补料架构（materials-first）· 定稿 2026-11-12

## 产品定调（用户原话）

「联网补充资料我认为是很重要和关键的，靠模型知识不够。」

由此确立的第一原则：**采料是一等公民，模型参数知识只是兜底**。课程质量上限由材料质量决定；模型记忆要么泛化、要么过期、要么编造（2026-11-12 实证：AI Agent 路径 15 节课全靠即兴合成还标"真实"）。

## 架构总览

```
goal 对话 ──T1 声明──┐
                     ├──► 统一执行器 material-collector ──► 用户资料库（入库+去重）
goal 全量文本 ─T2 信号─┤     （检索→选源→抓取→LLM抽取带引文→Pack）        │
                     │                                                    │ 库优先
goal 全量文本 ─T3 价值闸┘                                                    ▼
                                              path 生成（planner / stage-designer）
                                                     │
                                                     ▼
                                     下游诚实契约：无材料不得称"真实"；有材料必须 materialRefs
```

## 三层触发（任一命中即采集，防御纵深）

| 层 | 机制 | 位置 | 状态 |
|---|---|---|---|
| **T1 goal 声明**（主通道） | goal 对话登记 `needsMaterial`（含真实性承诺依赖类：用户要真实案例/公开复盘 → 必须 public need）；能对话区分私有/公开、请用户上传；async 模式下与规划并行 | goal-conversation → path.coordinator | 已有 + 2026-11-12 补承诺绑定 |
| **T2 path 思考触发** | 声明缺失时，path 拿全量 goal 文本跑确定性检测：真实承诺信号 / 文档依赖信号 → 派生 need | `deriveMaterialNeedsFromGoalText` | 2026-11-12 新增 |
| **T3 研究价值闸** | 即使无任何信号：事实/机制/框架/法规/数据类领域（模型记忆不可靠的领域）默认带锚点资料——从 key stages 派生锚点 need；纯训练目标（口语/习惯/体能）不命中零误伤 | 同上（stages 入参） | 2026-11-12 新增 |

**为什么不只在 goal 层做**：goal 是聊天（延迟敏感、方向未定、案例类词形漏判实证）；path 是交货层（拿全量、承受后果）。**为什么不只在 path 层做**：goal 能对话（私有/公开只有它能问）、queries 更准、能尽早并行启动。三层各自的失败模式互不重叠。

## 执行与存储（已就绪，未改动）

- **统一执行器**：material-collector（search→选源→fetch→LLM 抽取带引文要点→Pack）；无引文要点进不了 pack；外部 HTTP 经 SSRF/超时/大小闸。
- **private/public 分流**（Frontier R1/R2）：private 不联网（公网注定搜不到，26 次 0 成功实证），由 goal 请用户上传。
- **入库 + 库优先去重**（批次 A）：抓到的正文落用户资料库；path 重建时按标题命中直接复用（零重采、零网络）。
- **async 生产模式**：path 不等联网——占位 + 后台采集（预算 90s）+ marker 幂等回填；确认方案即触发 path build，async 采集与规划并行 = 事实上的预取。
- **fail-open**：采集失败绝不阻塞路径生成。

## 下游诚实契约（2026-11-12 已建，与采料闭环）

1. **goal 层承诺纪律**：未登记 needsMaterial → 禁止承诺「真实案例/都能查到/不拿编的」。
2. **planner 软校验** `PLANNING_SOURCE_HONESTY`：无材料时 summary/milestone 不得出现「真实/公开记录」措辞 → 带反馈重试。
3. **stage-designer** `TASK_NARRATION_GUARD`：题面无材料不得称真实（`来源诚实`）；有材料必须 materialRefs（sectionId + 逐字 quote）。

契约的语义翻转：没有这架构时规则是「别撒谎」（不得称真实）；有了这架构规则变成「兑现」——T1-T3 采到料，就允许且必须用真材料。

## 触发词形速查（material-need-origin.ts）

- 真实承诺：`真实案例|真实记录|真实对话|公开(跑偏|事故|调用|训练)?(记录|日志|复盘)|不拿编的|都是真事`
- 文档依赖：`官方文档|API文档|开发文档|技术规范|白皮书|操作手册|使用指南`
- 研究价值：`机制|原理|框架|工具|平台|模型|算法|法规|法律|标准|规范|政策|经济|金融|心理|医学|历史|行业|数据|统计|案例|事件|版本|API|SDK|技术|科学|市场`（去重计数，有关键阶段 ≥1、无 ≥2 触发）
- 派生上限 3 条（与 MATERIAL_COLLECTION_MAX_NEEDS 对齐）——兜底闸是补漏不是主力。

## 遗留（P1/P2）

- **版本/时效锚**：MaterialNeed 已有 version/publisher 字段，采集结果应带采集时间与来源时效（法规修订版、API 版本）——planner 消费时提示「以材料版本为准」。
- **课中补料**：教学回合里学生问到材料外的事实（新事件/新数据）时，teaching-supplement 已有联网链路，与研究价值闸的词形可共用一份。
- **观察指标**：T2/T3 派生命中率、派生采集的 pack 被下游 materialRefs 引用率（引用率低 = 派生 query 质量差，该调词形不是该关闸）。
