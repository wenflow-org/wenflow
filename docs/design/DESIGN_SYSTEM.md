# AI学习平台 - 视觉设计系统

## 设计原则

| 原则 | 说明 |
|------|------|
| 护眼优先 | 学习平台需长时间使用，避免高对比度导致的视觉疲劳 |
| 专注导向 | 柔和中性背景 + 清晰内容层次，减少干扰 |
| 正向激励 | 用少量亮色强调成就和进步，而非广告式醒目 |
| 专业可信 | 偏向教育/科技感的稳重色调 |
| 暗色模式 | 必须支持，夜间学习友好 |

## 语义化状态色

### 成功/完成
- 颜色: `#2ECC71`
- 用于: 任务完成、成就解锁、成功提示
- 背景: `rgba(46, 204, 113, 0.1)`
- 边框: `rgba(46, 204, 113, 0.2)`

### 进行中
- 颜色: `#3498DB`
- 用于: 当前任务、活跃状态、进度指示
- 背景: `rgba(52, 152, 219, 0.1)`
- 边框: `rgba(52, 152, 219, 0.2)`

- 用于: 未开始内容、禁用状态
- 背景: `rgba(149, 165, 166, 0.1)`
- 边框: `rgba(149, 165, 166, 0.2)`

- 颜色: `#E74C3C`

- 背景: `rgba(231, 76, 60, 0.1)`
- 边框: `rgba(231, 76, 60, 0.2)`

## 设计决策记录

### 为什么选择温润蓝？
1. **专业可信**：蓝色在教育和科技领域广泛使用，传达专业感
2. **护眼友好**：中等饱和度的蓝色比高饱和度更护眼
3. **区分度高**：与常见的紫色/绿色品牌色区分明显
4. **暗色模式友好**：蓝色在暗色模式下表现良好

### 为什么选择琥珀橙作为强调色？
1. **正向激励**：橙色传达温暖、活力、成就感
2. **对比适度**：与蓝色形成互补但不过于强烈
3. **成就关联**：类似奖杯/勋章的金色感

### 为什么避免纯黑/纯白？
1. **护眼**：纯黑纯白对比度最高，长时间观看易疲劳
2. **柔和**：略带色调的中性色更舒适
3. **层次感**：多级灰度提供更多层次选择
