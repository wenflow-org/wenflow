## 三、仍然存在的产品问题（按优先级）

1. **材料检索质量**：collector 能触发，但选源常落在二手材料——u15 把豆瓣书评当真（status=ok）、u03/u04 的行业报告/学术论文被正确拒收但也没拿到法条/年报原文。下一步应加强「一手源优先」与按资料类型限定域名（法规/统计/年报）。
2. **路径体量跨 run 不稳定**：同一 u05 第一批 2 阶段/4 课、第二批 4 阶段/15 课；u06 3/12 → 4/14。goal 收敛的「范围大小」受拟真人设可用时间/表述影响，缺少跨 run 的稳定性护栏。
3. **路径长度 vs 学习日预算**：19 条路径平均 10.8 课，7-9 个模拟日只能完成一半；多数 case 报 `max-days-reached`。不是产品失败，但说明「排课粒度」与「短期冲刺型目标」的匹配需要产品决策。
4. **provider 吞吐**：5 并发课堂下单日 4-13 分钟，批次墙钟时间主要耗在 provider 排队；批量跑数应按容量限并发。
5. **标题剧透启发式已收紧**：首版把 u07「…结论是什么」误判为剧透，已从强信号词表移除「结论是」，只保留「答案是/真相是/其实是/一招/秒懂」等断言式信号。
