# Admin 实验室功能规格文档

**版本**: 1.0  
**日期**: 2026-03-20  
**目标团队**: 前端 + 后端（非 Agent）  
**核心目标**: 开发者测试工具 + 监控面板（不接触真实用户数据）

---

## 🎯 改版概述

### 核心原则

1. **数据隔离**: Admin 数据与正式平台数据物理隔离
2. **账号独立**: Admin 使用独立账号系统（非正式用户账号）
3. **测试专用**: 所有功能用于开发测试，不接触真实用户数据
4. **Agent 不变**: 调用现有 Agent，添加日志包装器

### 架构定位

```
┌─────────────────────────────────────────┐
│          正式平台（生产环境）            │
│          - 真实用户使用                  │
│          - 游客模式 + 邮箱绑定           │
│          - 开发者不可见用户数据          │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│          Admin 实验室（测试环境）         │
│          - 开发者使用                    │
│          - 模拟用户测试                  │
│          - 完整日志可见                  │
└─────────────────────────────────────────┘
```

### 1.1 账号类型

**管理员账号**:
- **用途**: 访问 Admin 实验室
- **创建方式**: 后台预设（非注册）
- **存储位置**: 独立管理员数据库（与正式用户隔离）

**账号类型**:

|------|------|------|
| 超级管理员 | 所有权限 | 系统所有者 |
| 开发者 | 除账号管理外所有权限 | 开发团队成员 |
| 测试员 | 测试工具 + 日志查看 | QA 团队 |

### 2.3 测试运行

**运行流程**:

```
1. 开发者配置测试参数
   ↓
2. 测试包装器调用现有 Agent
   ↓
3. 模拟用户输入（根据行为模式）
   ↓
4. 记录完整交互日志
   ↓
5. 显示测试结果
```

**日志记录内容**:

| 数据类型 | 记录 | 用途 |
|----------|------|------|
| 用户输入 | ✅ | 验证输入理解 |

| 生成路径 | ✅ | 验证路径逻辑 |
| 任务内容 | ✅ | 验证任务难度 |
| API 调用 | ✅ | 验证接口性能 |
| 错误信息 | ✅ | 定位问题 |
| 耗时 | ✅ | 性能分析 |

## 5️⃣ 数据隔离与安全

### 5.1 数据隔离

**物理隔离**:

```
正式平台数据库:
- 表：users, learning_paths, tasks, ...
- 访问：正式平台 API
- Admin 不可访问

Admin 实验室数据库:
- 表：admin_users, test_sessions, test_logs, ...
- 访问: Admin API
- 正式平台不可访问
```

**逻辑隔离**:

- Admin API 与正式平台 API 使用不同路由前缀
- Admin API 需要管理员 Session
- 正式平台 API 不接受管理员 Session

---

### 5.2 安全规则

**访问控制**:

| 规则 | 说明 |
|------|------|
| Admin 账号不能访问正式平台数据 | 物理隔离 + 权限检查 |
| 正式平台用户不能访问 Admin | 路由隔离 + 权限检查 |
| 所有 Admin 操作记录审计日志 | 可追溯 |
| 测试数据 30 天后自动清理 | 防止数据堆积 |

**审计日志**:

- 记录所有 Admin 登录
- 记录所有数据查看操作
- 记录所有测试运行
- 日志保留 90 天

## 📞 常见问题

**Q: Admin 能看到正式平台用户数据吗？**  
A: 不能。物理隔离 + 权限控制，Admin 只能看到测试数据。

**Q: 测试数据会污染正式平台吗？**  
A: 不会。独立数据库，独立 API 路由。

**Q: 测试 Agent 和正式 Agent 是同一个吗？**  
A: 是。测试包装器调用现有 Agent，不修改 Agent 本身。

**Q: 测试数据保留多久？**  
A: 30 天后自动清理。

**Q: 可以导出测试报告吗？**  
A: 可以。支持导出 JSON/CSV 格式。
