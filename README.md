# AI 学习平台

> 当 AI 在学怎么像人一样思考，我们在教人怎么更会思考。

---

## 为什么存在？

1946 年，爱因斯坦等科学家警告：

> "原子释放出的力量改变了一切，除了我们的思维方式。"

80 年过去了。2026 年，AI 释放的力量不亚于原子能。但我们的教育，还在用工业时代的方式。

**我们选择另一条路**：不是用 AI 提高传统学习效率，而是培养 AI 时代需要的新思维。

---

## 核心理念

### 思维 vs 工具

我们教的是**思维（道）**，而非**工具（技）**。

| 思维（道）| 工具（技）|
|---------|---------|
| 看到联系、识别模式 | 循环怎么写 |
| 逻辑结构、系统框架 | 单词怎么拼 |
| 工具选择、场景决策 | 标准答案 |
| 问题定义、提炼本质 | 知识记忆 |

**工具会过时，思维永流传。**

### 问题创建

世上最难的问题，是自己给自己出的题。

| 别人给的问题 | 你创建的问题 |
|------------|------------|
| 再难也有解法 | 没有标准答案 |
| 出题人知道答案 | 没有明确边界 |
| 有标准路径 | 黑暗中摸索 |
| 可以答对/答错 | 只有更理解 |

**真正有价值的成长，发生在没有标准答案的地方。**

## AI 时代需要的 5 种能力

| 能力 | 描述 | 而非 |
|-----|------|-----|
| **问题定义能力** | 从模糊困惑中提炼清晰、可探索的问题 | 知识记忆 |
| **系统思维能力** | 看到事物之间的联系和整体结构 | 单点解题 |
| **判断力** | 在信息过载中辨别真伪、权衡取舍 | 标准答案 |
| **AI 协作力** | 与 AI 有效对话，让它成为你的思维伙伴 | 独立实现 |
| **创造力** | 跨越边界，产生新的连接和可能性 | 重复练习 |

## 平台功能

### 🎯 核心学习系统

**对话式目标收集** - 通过 5-8 轮自然对话，帮助用户澄清真正想学什么，而非填表式需求收集。

**智能学习路径生成** - 将模糊目标转化为可执行的周/天级别任务，支持动态难度调整。

**对话式学习执行** - Round-based 交互式学习，每轮聚焦一个知识点，AI 提问→用户回答→AI 反馈。

**ZPD 分层 AI 辅导** - 根据用户水平（新手/高级初学者/胜任/精通/专家）动态调整辅导策略。

### 📊 学习状态追踪（LSS/KTL/LF/LSB）

借鉴运动科学量化模型，科学追踪学习状态：

| 指标 | 名称 | 说明 |
|------|------|------|
| **LSS** | 学习压力评分 | 基于任务难度、时长、认知负荷 |
| **KTL** | 知识掌握度 | 长期积累，42 天衰减因子 0.95 |
| **LF** | 学习疲劳度 | 短期累计，7 天衰减因子 0.70 |
| **LSB** | 学习状态平衡 | LSB = KTL - LF，预警过度学习 |

### 🏆 激励与评估

- **成就系统**：14 个预定义成就，自动解锁，XP 奖励
- **学习报告**：周报/月报自动生成，数据可视化，智能建议
- **反馈系统**：多维度评分（帮助性/清晰度/难度）+ 文字评论

### 🤖 Agent 系统（v3.0 核心）

**MCP Agent 架构** - 15+ 官方 Agent，插件化扩展：
- `content-agent`、`tutor-agent`、`path-agent`、`progress-agent`
- `goal-conversation-agent`、`peer-agent`、`summary-agent`

**Arena 竞技场** - 多 Agent 并行对比，盲测评估，数据驱动选择最优方案。

### 👥 用户系统

- **认证**：正式用户（注册/登录）
- **自定义 Agent**（新增）：用户可创建专属 Agent，配置 Prompt、模型参数、Skill 插件
- **开发者工具**（新增）：代码仓库、MCP 配置、API 访问、执行日志

### 🛠️ 管理端

完整的管理后台，支持：用户管理、Agent 监控、Prompt 管理、Arena 实验、平台统计、调试沙盒。

## 技术架构

### 后端技术栈
- **框架**: Node.js + Express + TypeScript
- **数据库**: PostgreSQL (生产) / SQLite (开发)
- **ORM**: Prisma（40 个数据模型）
- **AI 服务**: DeepSeek / GLM / Gemini（兼容 OpenAI API）
- **认证**: JWT + bcrypt
- **日志**: Winston
- **验证**: Zod
- **安全**: Helmet + CORS

### 前端技术栈
- **框架**: Vue 3 + TypeScript + Vite 5
- **UI 库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **图表**: Chart.js + vue-chartjs
- **样式**: Sass + CSS 变量

### Agent 架构
- **协议**: MCP (Model Context Protocol)
- **插件系统**: 支持自定义 Skill 插件（18+ 内置 Skill）
- **注册表**: 动态注册和发现
- **执行引擎**: 并行执行和负载均衡

### DevOps
- **容器化**: Docker + Docker Compose
- **反向代理**: Nginx
- **SSL**: 自动证书生成
- **部署脚本**: PowerShell + Bash
- **健康检查**: 自动化监控

## 快速开始

### 环境要求

- Node.js >= 18
- PostgreSQL (生产) / SQLite (开发)

### 安装

```bash
# 后端
cd backend
npm install
cp .env.example .env
npx prisma generate
npx prisma db push
npm run dev

# 前端
cd frontend
npm install
cp .env.example .env
npm run dev
```

### 访问

- 前端: http://localhost:5173
- 后端: http://localhost:3001

## 教育理论基础

### 6 大基石

1. **认知负荷理论** - 避免信息过载
2. **自我导向学习** - 用户自主决定
3. **Dreyfus 五阶段模型** - 动态评估用户阶段
4. **最近发展区 + 支架** - 难度略高于当前水平
5. **形成性评估** - 即时反馈
6. **刻意练习** - 针对弱点突破
