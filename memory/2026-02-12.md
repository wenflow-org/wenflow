### 核心Bug修复
**Critical Bug**: Prisma Error P2025 - "Record to update not found"
- **问题位置**: `backend/src/services/learning/learning.service.ts:170`
- **问题原因**: `generateLearningPath` 方法尝试更新一个不存在的 `LearningGoal`，导致整个学习路径生成流程失败
- **修复方案**: 修改逻辑为先查找现有目标，如果存在则更新，不存在则创建新目标
- **修复代码**:
  ```typescript
  // 5. 更新或创建学习目标，关联学习路径
  const existingGoal = await prisma.learningGoal.findFirst({
    where: { userId: data.userId, description: data.description }
  });

  if (existingGoal) {
    await prisma.learningGoal.update({
      where: { id: existingGoal.id },
      data: { learningPathId: learningPath.id }
    });
  } else {
    await prisma.learningGoal.create({
      data: {
        userId: data.userId,
        description: data.description,
        subject: data.subject,
        learningPathId: learningPath.id
      }
    });
  }
  ```
